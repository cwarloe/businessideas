# Discovery and test run record

Copy this file into the idea folder for a particular run. Keep the plan and results together. Fill the plan before the work, then preserve any change to it with a date and reason. Use anonymized summaries in the public repository.

## Evidence

For discovery, report recent behavior, exact past purchase if known, payer/approver, alternatives and reasons. For a paid trial, record the price actually paid and refunds. Track prospective contact, eligible exposure, first paid buyer and eligible repeat buyer as different denominators. Mark friends, discounts, sponsored purchases and other circumstances that could explain the result.
