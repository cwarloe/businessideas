# Stage 1 compliance register

**Business:** Oats, Etc. (Modern Comfort Kitchen), a proposed Boise-area oatmeal breakfast service.  
**Scope:** Stage 1 is a small break-even experiment, not a living-wage plan and not a restaurant build-out. See `docs/oats-and-more/research/pilot-and-equipment.md` and the OE Numbers draft notes.  
**As of:** 2026-11-11. No item is DONE. Nothing has been filed or paid from this work.  
**How to use this file:** The summary tables give the official columns. The item notes under each table add context. On a phone, you can skip to the category you need.

This register is not a legal opinion. Regulations change. The agency's answer governs.

## How to read the columns

| Column | Meaning |
|---|---|
| ID | Stable identifier for this row. |
| Item | The permit, license, registration, policy, tax obligation, or filing. |

| Due or renewal date | A published due date, or **not confirmed**. |
| Source link | The official page opened this session, when there is one. |
| Date checked | 2026-11-11 for every row touched in this first build. |
| Verification | VERIFIED-this-session or UNVERIFIED. |
| Next action | The next concrete step. Do not treat it as an instruction to file today. |
| Blocked-on | What actually stops progress on this row, or "none" if you could start it now. |
| Can it wait | Whether it can wait until after the one-day trial path is clear. |

Recommended lightest path, in one paragraph: call Central District Health first; for a one-day public-event booth the lightest published licensed path is a Temporary Food Establishment license (published one-day fee $35, apply at least 30 days ahead); do not assume a private office morning is that license or homemade food; do not assume home cooking for a walk-up stand; handle city, tax, kitchen, and insurance after the classification. Details are in [start-here.md](start-here.md).
